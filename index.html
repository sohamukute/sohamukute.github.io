About

I'm Soham Kute, a Systems and Backend Engineer based in Mumbai, studying Electronics Engineering with an Aerospace minor at Veermata Jijabai Technological Institute (VJTI) (2023–2027).

I focus on building resilient server side architectures from first principles: custom binary network protocols using raw Java NIO selectors, high concurrency event ticketing engines with distributed Sagas, and recommendation systems handling tens of millions of interactions.

Outside of backend systems, I mentor autonomous robotics at SRA VJTI, solve competitive programming problems (LeetCode 1631, CodeChef 1610 3☆), and contribute to open source infrastructure like FFmpeg and libmicrodns.
